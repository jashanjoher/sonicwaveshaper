SonicWaveshaper - how to install on Windows

1. Copy the SonicWaveshaper.vst3 folder into C:\Program Files\Common Files\VST3\
   (copy the whole folder, not just the file inside it).
2. Optional: run SonicWaveshaper.exe to use the plugin on its own.
3. Windows may ask for permission because you are copying into a system folder. Click Yes.
4. Restart your music app so it finds the plugin.

If Windows SmartScreen says it protected your PC, click More info, then Run anyway.
The build is not code-signed yet.
