SonicWaveshaper - how to install on a Mac

1. Drag SonicWaveshaper.vst3 onto the 1-VST3-folder icon.
2. Drag SonicWaveshaper.component onto the 2-AU-folder icon.
3. Optional: drag SonicWaveshaper.app onto 3-Applications to run it on its own.
4. macOS may ask for your password. That is normal, these folders are shared by all apps.
5. Restart your music app so it finds the plugin.

If macOS says the app cannot be opened, right-click it and choose Open.
